Installer le socle central

Le script est long (plus de 400 lignes) : impossible à sélectionner au doigt. Le bouton ci-dessous le copie en entier, d'un seul coup.

Avant de commencer. Ce script s'applique au projet Supabase qui fait déjà tourner gardiens.idf.immo. Il ne crée pas de seconde base : il transforme celle-ci en socle commun aux quatre réseaux.

Il a été exécuté et vérifié sur une copie complète de la base avant de t'être donné. Il peut être lancé deux fois sans rien casser.

gardiens.idf.immo ne bougera pas. La table que le site lit devient une vue portant le même nom et les mêmes colonnes. Vérifié : la fiche du gardien, ses opportunités, ses primes et son journal reviennent à l'identique après migration.

Chargement du script…

Ensuite, dans Supabase

1

Ouvre supabase.com et connecte-toi.

2

Clique sur ton projet — celui qui sert déjà les gardiens. Il n'y en a qu'un, tu ne peux pas te tromper.

3

Dans la colonne de gauche, cherche l'icône SQL Editor (une petite feuille avec « SQL » dessus).

4

En haut, clique sur « New query ». Une grande zone blanche vide apparaît.

5

Appuie longuement au milieu de la zone blanche, puis choisis « Coller ». Le script s'écrit tout seul.

6

En bas à droite, clique sur le bouton vert « Run ».

Si un message « Potential issue detected » apparaît, c'est normal : Supabase prévient toujours quand un script modifie des tables. Clique sur « Run this query ».

7

Attends quelques secondes. Tu dois voir « Success. No rows returned ».

C'est la bonne réponse : le script installe des tables, il n'affiche rien.

Puis vérifie que rien n'a bougé

Toujours dans le SQL Editor, efface tout, colle cette seule ligne et clique sur Run :

Tu dois voir la liste des gardiens, avec les mêmes colonnes qu'avant : id, prenom, nom, email, telephone, residence, commune, iban, cree_le. Si c'est le cas, le site des gardiens est intact.

Si quelque chose se passe mal

Ne recommence pas dix fois : envoie-moi le message d'erreur en entier, tel qu'il s'affiche. Il me dit exactement quelle ligne a coincé.
